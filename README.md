# MELODI Géographie

Référentiel géographique administratif (pays, régions, villes et zones commerciales).

## Informations du module

| Propriété | Valeur |
|---|---|
| Catégorie | localization |
| Version | 1.0.0 |

## Dépendances

- MELODI : `base`
- Python : aucune

## Installation dans MELODI

Dans une copie de MELODI, ajoutez ce dépôt comme sous-module à `modules/melodi_geo` :

```bash
git submodule add -f git@github.com:Byt3Lab/melodi_geo.git modules/melodi_geo
```

Si ce chemin contient déjà des fichiers, sauvegardez-les et déplacez-les avant d'ajouter le sous-module.
